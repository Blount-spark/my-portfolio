# 灵感杂货铺 · 个人作品展示网页

一个不设领域边界的个人作品集：代码、影像、写作、手工……只要一个想法真的被做出来了，它就会出现在这面墙上。

- **技术栈**：Vite + React 18，纯 CSS（无 UI 库、无路由库），依赖极少
- **风格**：活泼多彩拼贴手账风（点阵纸背景、胶带、歪斜卡片、贴纸标题）
- **作品详情**：混合模式——站内「制作手记」详情页 + 外部平台链接，每条作品任选或兼有
- **部署**：构建产物是纯静态文件，`dist/` 可传到任意静态托管（GitHub Pages / Vercel / Netlify / 对象存储）

## 快速开始

```bash
npm install        # 安装依赖（仅首次）
npm run dev        # 本地开发，改文件即时生效
npm run build      # 构建，产物在 dist/
npm run preview    # 本地预览构建结果
```

## 每天怎么用：只改一个文件

全部内容都在 **`src/data/works.js`** 里，改完保存即可，不需要动任何组件代码。

### 1. 个人信息 `PROFILE`

名字、一句话简介、关于我的段落、社交链接（GitHub / 公众号 / 小红书 / 邮箱）。

### 2. 分类 `CATEGORIES`

默认有：代码、影像、写作、手工、设计、奇思妙想。可以自由增删——想加「烘焙」「乐器」就加一行，卡片和筛选按钮会自动跟上。

### 3. 作品 `WORKS`

每条作品的字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `id` | ✅ | 唯一编号，别重复 |
| `title` | ✅ | 作品名 |
| `category` | ✅ | 分类 id，需在 `CATEGORIES` 中存在 |
| `date` | ✅ | 完成年月，如 `'2026-08'` |
| `desc` | ✅ | 一两句简介：做了什么、花了多久、有什么有意思的细节 |
| `emoji` | 二选一 | 封面表情符号 |
| `img` | 二选一 | 封面图片路径（见下方「配图」），写了 `img` 就优先用它 |
| `gradient` | ✅ | 封面渐变色 `[起, 止]`，如 `['#a8edea', '#fed6e3']` |
| `tags` | ✅ | 自由标签，1~3 个 |
| `link` | ✅ | 外部链接（GitHub / 文章 / 视频），暂无就写 `'#'` |
| `detail` | ❌ | 站内详情页，见下 |

### 4. 混合模式：详情放哪，三种选法

```js
// A. 纯外链：详情发在社交媒体上，卡片显示「看看去 →」，点了跳出去
{ ..., link: 'https://mp.weixin.qq.com/xxxx' }

// B. 站内手记：加 detail 字段，卡片出现「📓 有手记」角标，点进去看详情页
{ ..., link: '#', detail: { story: ['第一段', '第二段', ...] } }

// C. 两者兼有：站内看手记，详情页底部有「去外部平台看完整版 ↗」
{ ..., link: 'https://...', detail: { story: [...] } }
```

`detail` 的完整结构：

```js
detail: {
  story: ['段落1', '段落2'],            // 制作手记，一段一个字符串
  gallery: ['/images/a.png', '/images/b.png'], // 可选：过程图
  captions: ['图1说明', '图2说明'],      // 可选：与 gallery 一一对应
}
```

### 5. 配图

把图片文件放进 `public/images/` 文件夹，然后在代码里写 `/images/文件名.png`：

- `img` 字段 → 替换卡片封面（详情页大封面也会用它）
- `detail.gallery` → 详情页里的过程图墙

建议单张控制在 500KB 以内（可用 [squoosh.app](https://squoosh.app) 压缩）。

## 项目结构

```
my-portfolio/
├── index.html              # 页面骨架、标题、SEO 描述
├── public/images/          # 放作品图片
└── src/
    ├── main.jsx            # 入口
    ├── App.jsx             # 页面组件：Hero / 作品墙 / 筛选 / 详情页
    ├── index.css           # 全部样式（拼贴风）
    └── data/works.js       # ★ 你唯一需要改的文件
```

## 部署上线

```bash
npm run build
```

把 `dist/` 整个文件夹上传即可。项目已配置 `base: './'`（相对路径），子目录托管（如 GitHub Pages 的 `用户名/仓库名`）也能直接工作；站内详情页使用 hash 路由（`#/work/1`），任何静态托管都无需额外重写规则。

## 常见问题

**改了 works.js 页面没变？** 确认跑的是 `npm run dev`（开发）而不是 `npm run preview`（预览的是上次构建的旧产物）。

**想删掉某条示例作品？** 从 `WORKS` 数组里整段删掉对应的 `{ ... },` 即可，注意保留逗号格式。

**想改配色/字体？** 都在 `src/index.css` 顶部的 `:root` 变量里（纸张色、墨色、卡片色）。
